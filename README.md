# Trace cortisol report prototype

A static, mobile-first prototype of the Trace cortisol report.

The report includes the welcome, cortisol rhythm, rhythm score, stress score, and characteristics screens. Use **Edit sample** to explore the example data and **Characteristics** to jump to the visualizations.

All readings and reference bands are illustrative design examples. The sample editor runs in the browser; the prototype has no server or data collection service.

## Preview

Open `index.html` directly or serve this directory with any static web server.

## Publish

GitHub Pages serves the root of the `main` branch. Push updates to `main` to publish.

Font licenses are included in `fonts/`.
